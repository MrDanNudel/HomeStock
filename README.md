# HomeStock — מה יש בבית?

אפליקציה משותפת לניהול מצרכים ומוצרי הבית, בעברית ובכיוון RTL.

## מה כבר עובד

- ארבע קטגוריות מוכנות: מצרכים, היגיינה, כביסה וניקוי
- סטטוס צבעוני: קיים, עומד להיגמר וחסר
- כמות ויחידה אופציונליות
- חיפוש, סינון ומיון בכל רשימה
- הוספה, עריכה ומחיקת מוצרים
- מצב קניות שמרכז את כל מה שחסר או עומד להיגמר
- שמירה מקומית בדפדפן
- סכמת Supabase מאובטחת ומוכנה לסנכרון משותף

## הרצה מקומית

```bash
npm install
npm run dev
```

## חיבור Supabase

1. יוצרים פרויקט Supabase ייעודי.
2. מפעילים את המיגרציה מתוך `supabase/migrations/001_initial.sql`.
3. מעתיקים את `.env.example` אל `.env.local` וממלאים URL ומפתח publishable בלבד.

אין להכניס לדפדפן `service_role` או secret key.
